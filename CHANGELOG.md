# Changelog

## [0.1.0] - Initial Release

### Added
- Model registry (`POST /models`)
- Reference distribution ingestion with histogram computation
- Production snapshot ingestion with background drift analysis
- KS test, PSI, and Jensen-Shannon divergence per feature
- Feature importance weighted scoring
- RED/YELLOW/GREEN severity classification
- Webhook-based alert dispatch
- Weekly health report generation (APScheduler)
- Manual report trigger endpoint
- Full end-to-end integration test suite
